# v0.4.83 — restore candidate uploads and reference layers on the v0.4.82 base

## What's restored

- Area Analysis accepts GeoJSON Polygon and MultiPolygon uploads in WGS84 (EPSG:4326), plus interactive drawing. Each polygon feature becomes a named candidate area in the existing Area Analysis list. You can select, rename, zoom, sort, delete and export as GeoJSON or CSV. The web browser does not send your uploaded file to a server. Max combined file size 25 MB and total 800 areas (including drawn areas).
- Area summaries again include per-factor area-weighted means (expand **Individual factor scores**), in addition to Baseline, Gap, Combined, coverage and changes from the original workbook defaults.
- The reference layer panel reads `meta.json` references and `data/references/*.geojson` generated by ArcGIS Pro Tool 5. It supports visibility and label toggles, hover labels, GLU fill with no polygon borders, and thin grey parcel boundaries. Native basemap labels remain above the analysis and reference overlays.

## Kept from v0.4.82

- ArcGIS toolbox and workbook are byte-for-byte identical to v0.4.82. No GIS rerun or schema change is required.
- Three Baseline/Gap/Combined tabs; editable factor weights; amenity routing; Combined split.
- Factor hover preview and correct category ordering; optional bivariate Combined layer with Baseline on Y, Gap on X; score-change overlay; default-comparison deltas; 100m grid export and configurable native analysis resolution.
- Draw polygon/rectangle/square; orthogonal snapping; Area Analysis and score CSV/GeoJSON exports; Vancouver Open Data browser layers.

## GitHub Pages update

Copy `index.html`, `app.js`, `area_analysis.mjs`, and `styles.css` into the repository, retaining the other `.mjs` modules and your live `data/grid.geojson`, `data/meta.json`, and `data/references/`. The bundled `demo_grid.geojson` and `demo_meta.json` are synthetic. The app requires MapLibre and polygon-clipping CDNs and the basemap API to be reachable; drawing/upload geometry calculations depend on polygon-clipping.

## Verification limitations

JavaScript syntax and isolated area/factor scoring tests passed. Full browser execution on local or published site could not be tested because local browser navigation was blocked by the environment. Real ArcGIS Pro execution was not attempted because only website code changed.
